資料解讀與限制

載入資料後顯示分析結果。

本資料為遊客人次統計，不代表不重複的個人遊客數。原始資料中的「-」視為缺失值，不當作 0；沒有資料的月份不列入分析。景點人次合計可能受各景點統計口徑影響，不一定代表不重複遊客數。

資料來源：花蓮縣政府觀光處，花蓮縣各觀光遊憩區遊客人數統計（最新）
分析期間：原始資料可用的 1–10 月；11–12 月原始資料為空白。
